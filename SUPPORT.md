# Support & Inquiry Portal

Welcome to the official support reference for **LTW Secure Code Generator**.

---

## 1. Scope of Public Support

This repository functions exclusively as a public documentation portal. The underlying application source code is maintained privately by [W L T Weerasinghe](main.wltweerasinghe.workers.dev). Consequently, public technical support is limited to documentation and architectural specifications published within this repository.

---

## 2. Channels & Procedures

### A. Documentation Issues & Typo Reports
If you encounter typographical errors, broken links, or formatting inaccuracies within the published Markdown files:
* Open a formal issue on our [GitHub Issue Tracker](../../issues).
* Complete all required fields using the standard issue template.

### B. Enterprise Licensing & Commercial Requests
If you represent an organization or enterprise seeking custom commercial licensing, explicit deployment rights, or permission to utilize project assets:
* Direct your inquiries to [W L T Weerasinghe](mailto:wltweerasinghe@gmail.com) via official, direct contact channels.
* Public issues requesting license exemptions or source code releases will be closed immediately in accordance with repository governance.

### C. Security Inquiries
For security disclosure protocols and private reporting channels, please refer the [Security Policy](./SECURITY.md).

---

## 3. Resolution Expectations

All documentation reports submitted via the issue tracker are reviewed periodically. As this project is independently managed, response times may vary depending on active development schedules.
