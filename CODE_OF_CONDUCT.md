# Public Contributor & Visitor Code of Conduct

## 1. Purpose & Core Philosophy

This public repository serves as an official documentation and metadata portal for the **LTW Secure Code Generator** project. We are dedicated to providing a respectful, professional, and safe environment for all community members, security auditors, developers, and visitors who interact with this repository.

Regardless of background, identity, level of experience, or technical expertise, every participant is expected to adhere to high standards of professional courtesy and constructive communication.

---

## 2. Expected Professional Standards

When participating in repository discussions, opening issues, or submitting documentation feedback, you are expected to:

* **Demonstrate Respect and Empathy:** Interact thoughtfully with the repository maintainer and fellow visitors, prioritizing constructive and professional dialogue.
* **Focus on Technical & Governance Value:** Ensure all comments, feedback, and issue submissions are focused directly on documentation accuracy, technical specifications, or security governance.
* **Respect Intellectual Property Boundaries:** Acknowledge and respect the proprietary nature of this project and the strict licensing terms governing this repository.
* **Accept Constructive Feedback:** Receive technical corrections or feedback graciously and maintain a collaborative tone in all communication threads.

---

## 3. Unacceptable Behaviors

Behavior that degrades the community environment or violates professional standards will not be tolerated. Unacceptable behaviors include:

* **Harassment or Derogatory Comments:** Personal attacks, inflammatory language, insulting remarks, or offensive commentary directed at the maintainer or community members.
* **Spam & Off-Topic Submissions:** Opening low-effort, automated, or irrelevant issues, promotional messages, or unsolicited spam.
* **License Evasion Tactics:** Attempting to use public issues or PR channels to demand, extract, or solicit private application source code in violation of project licensing terms.
* **Unprofessional Conduct:** Persistent disruption of repository issue tracking or engaging in adversarial behavior.

---

## 4. Enforcement & Moderation Protocol

The repository maintainer ([W L T Weerasinghe](main.wltweerasinghe.workers.dev)) reserves the absolute right and authority to enforce this Code of Conduct to preserve repository integrity. Enforcement actions may include:

1. **Issue Closure & Cleanup:** Immediate closure and hidden moderation of issues or comments that violate these guidelines.
2. **Interaction Restrictions:** Temporary or permanent restriction of user access to issue tracking and pull request submission features.
3. **Platform Reporting:** Escalation of abusive behavior, harassment, or spam directly to GitHub Trust & Safety for account-level action.
