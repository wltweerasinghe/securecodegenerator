## [1.0.0] - 2026-10-08

### Added
- Initial public release of official project documentation and repository governance frameworks.
- Added comprehensive `README.md` defining client-side Web Crypto architecture and zero-trust design parameters.
- Formulated custom `LICENSE` detailing strict Source-Available terms, IP protection, AI scraper prohibitions, and trademark restrictions.
- Established `SECURITY.md` establishing vulnerability disclosure workflows and client-side isolation boundaries.
- Introduced `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, and `SUPPORT.md` establishing public engagement standards.
- Integrated repository configuration assets including `.editorconfig`, `.gitignore`, `CITATION.cff`, and `.github` templates.
