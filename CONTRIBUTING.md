# Repository Contribution Guidelines

Thank you for visiting the official repository directory for **LTW Secure Code Generator**.

---

## 1. Repository Status & Scope

Please be aware that this public repository operates under a strict **Source-Available & Proprietary Framework**. 

* **Documentation Portal Only:** This public repository is intentionally dedicated **strictly to project documentation, legal governance, and repository configuration files**.
* **Private Application Source:** The application source code, execution files, and development pipelines are kept completely private and are **not pushed or hosted** in this public git repository.

---

## 2. Pull Request Policy

Due to the non-public nature of the core application code:

* **Code Pull Requests:** Pull requests aimed at adding application features, modifying frontend components, or introducing scripts will be automatically closed, as the source code is not present in this tree.
* **Documentation Pull Requests:** Pull requests focused on correcting formatting, fixing typographical errors, or improving clarity within the existing public markdown documentation files may be reviewed at the maintainer's discretion.

---

## 3. Issue Submission Protocol

If you wish to submit feedback regarding the published documentation:

1. **Check Existing Issues:** Search the repository issue tracker to ensure your topic has not already been reported or addressed.
2. **Use Official Templates:** Always utilize the provided [Documentation Issue Template](./.github/ISSUE_TEMPLATE/bug_report.md) when opening a new ticket.
3. **Be Specific:** Clearly state which document file (`README.md`, `LICENSE`, `SECURITY.md`, etc.) your feedback pertains to.
4. **Maintain Professional Tone:** Ensure all submissions strictly align with our [Code of Conduct](./CODE_OF_CONDUCT.md).

Thank you for respecting the governance and security boundary of this repository!
